# 6. Oscilloscope — College Lab Lesson

Static multipage SPA for measuring amplitude, period, and frequency with a CRO. Light neutral theme, left-rail progress, immersive hover-driven practical, graph-paper tracing example. GitHub Pages friendly (relative paths, no backend).

## View on GitHub Pages

`https://ancient7999.github.io/oscilloscope-lesson/`

## Local preview

Open `index.html` in a browser (or serve the folder). Assets load via relative paths.

## Structure

- `index.html` — hash-routed views + end-of-lesson optional extras
- `css/styles.css` — layout, theme, practical, cursor
- `js/app.js` — navigation, animated background, custom cursor, hover practical
- `assets/` — CRO, function generator, EEG, graph paper
