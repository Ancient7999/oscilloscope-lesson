# 6. Oscilloscope — College Lab Lesson

Static, shareable HTML lesson for measuring amplitude, period, and frequency with a CRO. Includes a beginner overview, apparatus photos, an interactive screen-reading practice, and a graph-paper tracing example.

## View on GitHub Pages

After Pages is enabled, open: `https://ancient7999.github.io/oscilloscope-lesson/`

## Local preview

Open `index.html` in a browser (assets load via relative paths).
